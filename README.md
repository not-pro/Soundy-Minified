# Soundy Minified

**Soundy Minified is the compact, low-memory edition of classic Soundy, rewritten in Zig.** It reduces RAM use by keeping only the selected keyboard pack and mouse sounds decoded, while reusing the audio engine. Classic Soundy preloads the entire sound catalog. All 240 sounds remain included in the download.

In version **1.0.1**, measured physical memory footprint with Tactile was about **14 MiB after startup** and **16 MiB after 168 profile changes**, down from **34.5 MiB in Minified 1.0.0**. These are medians of three runs on the development Mac without input monitoring; the classic Rust app was not benchmarked separately. Actual usage depends on the selected sounds and system.

Soundy Minified adds keyboard and mouse sounds to macOS. Mechanical keys, typewriters, electronic tones, and playful effects make everyday computer use more enjoyable.

Pick a sound to match your mood: **40 keyboard profiles and 15 mouse sound options**. All 240 sounds are bundled with the app — no extra downloads needed.

Soundy Minified lives in the menu bar. Choose keyboard and mouse sounds separately, preview them, adjust the volume, or pause playback. Your settings are saved between launches. You can turn off mouse sounds while keeping keyboard sounds enabled.

No accounts, subscriptions, or time limits. Everything runs locally.

## Getting started

1. Download the `.pkg` from the [latest release](https://github.com/not-pro/Soundy-Minified/releases/latest): `arm64` for Apple Silicon or `x86_64` for Intel.
2. Open the installer, click **Continue → Install**, then **Close**. Launch Soundy Minified from Applications. A ZIP archive is also available for manual installation.
3. In Soundy Minified's menu, click **Allow Input Monitoring…** and enable access in macOS settings. Restart Soundy Minified if prompted.
4. Choose **Keyboard Sound** and **Mouse Sound**, adjust the volume, and start typing.

Requires **macOS 13 or later**.

Keyboard sounds are unavailable in protected password fields and while Secure Keyboard Entry is enabled: macOS blocks these keystrokes from reaching other apps. Sounds resume when secure input ends. Learn more: [Apple — Secure Event Input](https://developer.apple.com/library/archive/technotes/tn2150/_index.html).

## Language

Soundy Minified supports **English, Russian, and Simplified Chinese**. On first launch, it uses the first supported language in your macOS language preferences, or English if none match.

Open **Language / Язык / 语言** in the menu bar and choose **English**, **Русский**, or **简体中文**. The change takes effect immediately and is saved for future launches. Sound pack names stay in English.

## Building

The application is rewritten in **Zig 0.17.0**, with no third-party libraries. It calls Apple’s AppKit, CoreGraphics and AVFAudio frameworks directly. The runtime contains no Rust, Swift or Objective-C source. Swift is used only for generating installer pages and icons.

You need Zig 0.17.0 and the macOS developer tools. The native installer is built with the system's `pkgbuild` and `productbuild` tools:

```sh
zig build test
zig build --release=small
zig-out/bin/soundy-minified --check
sh scripts/package.sh
```

The PKG, ZIP, and checksum files will be created in `dist/`. Installer pages are generated by `scripts/installer-pages.swift`, with configuration in `macos/installer/`. To regenerate the icons, run `swift scripts/export-icons.swift`.

For development, use `zig build run`. CLI options include `--sounds-dir PATH`, `--check`, `--preview`, `--preview-mouse`, `--smoke-test`, `--version` and `--help`. `--check` decodes all 240 WAVs without opening audio output or monitoring input. `--smoke-test` checks the native menus in all three languages, all keyboard/mouse cache selections, switching during playback, failed-load recovery and saved settings in an isolated defaults suite, then exits; it opens audio output but never starts input monitoring.

`zig build -Dtarget=x86_64-macos.13.0 --release=small` builds for Intel on an Apple Silicon Mac. CI builds and packages both architectures on native macOS runners. Artifacts are attached to workflow runs; pushing a tag matching `VERSION` (for example `v1.0.1`) publishes a release. Binaries use ad hoc signing, as in the original project.

Only the selected keyboard pack and mouse pair are kept decoded in memory (at most 12 buffers). Changing a sound loads the replacement on the serial audio queue, then stops old playback, frees obsolete buffers/nodes, and reuses the engine and compatible voice pools. A failed load keeps the working selection and restores its preferences. All 240 files remain bundled and are validated by `--check`.

Translations and language display names live in `assets/i18n.json`. The app reads `Contents/Resources/i18n.json` once at launch (the source file during development), validates every language/key, and keeps owned UTF-8 strings for lookups. Editing the JSON requires no Zig code changes; rebuilding the signed app bundle includes the new file.

This port preserves the [original Soundy](https://github.com/n-bautin/Soundy) profiles, WAVs, three languages, menu behavior, input routing, six voices per PCM format, limiter and 15 ms sample gate. Keyboard repeats are ignored; mouse press and release have separate samples. Pending input sounds older than 100 ms are dropped, and pending input sounds are bounded to 32 slots.

The app and installer use `dev.soundy.minified.app`, with separate settings and Input Monitoring permission. The package installs `/Applications/Soundy Minified.app`, with the executable `soundy-minified` and a violet-blue icon. It can coexist with the original Soundy app.

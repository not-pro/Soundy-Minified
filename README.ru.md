# Soundy Minified

Soundy Minified добавляет звуки клавиатуре и мыши на macOS. Механические клавиши, печатные машинки, электронные сигналы и необычные эффекты делают повседневную работу за компьютером приятнее.

Выберите звучание под настроение: **40 профилей клавиатуры и 15 вариантов звука мыши**. Все 240 звуков уже внутри приложения — ничего дополнительно устанавливать не нужно.

Soundy Minified живёт в строке меню. Там можно выбрать звуки клавиатуры и мыши по отдельности, послушать пример, настроить громкость или поставить всё на паузу. Настройки сохраняются между запусками. Звук мыши можно отключить, оставив клавиатуру.

Без аккаунтов, подписок и ограничений по времени. Работает локально.

## Начать пользоваться

1. Скачайте `.pkg` из [последнего релиза](https://github.com/not-pro/Soundy-Minified/releases/latest): `arm64` для Apple Silicon или `x86_64` для Intel.
2. Откройте установщик, нажмите **«Продолжить» → «Установить»**, затем **«Закрыть»**. Запустите Soundy Minified из «Программ». Также доступен ZIP для ручной установки.
3. В меню Soundy Minified нажмите **«Разрешить мониторинг ввода…»** и включите доступ в настройках macOS. Если система попросит, перезапустите Soundy Minified.
4. Выберите **«Звук клавиатуры»** и **«Звук мыши»**, настройте громкость и печатайте.

Нужна **macOS 13 или новее**.

В защищённых парольных полях и при включённом Secure Keyboard Entry звуки клавиатуры недоступны: macOS блокирует передачу этих нажатий сторонним приложениям. После выхода из защищённого ввода звуки возобновляются. Подробнее: [Apple — Secure Event Input](https://developer.apple.com/library/archive/technotes/tn2150/_index.html).

## Язык

Soundy Minified поддерживает **английский, русский и упрощённый китайский**. При первом запуске выбирается первый поддерживаемый язык из настроек macOS. Если совпадений нет, используется английский.

Откройте **Language / Язык / 语言** в меню приложения и выберите **English**, **Русский** или **简体中文**. Язык меняется сразу и сохраняется между запусками. Названия звуковых наборов остаются на английском.

## Сборка

Для сборки нужны Zig 0.17.0 и инструменты разработчика macOS. Нативный установщик создаётся системными `pkgbuild` и `productbuild`:

```sh
zig build test
zig build --release=small
zig-out/bin/soundy-minified --check
sh scripts/package.sh
```

Готовые PKG, ZIP и контрольные суммы появятся в `dist/`. Страницы установщика генерирует `scripts/installer-pages.swift`, настройки находятся в `macos/installer/`. Иконки можно пересоздать командой `swift scripts/export-icons.swift`.

Приложение переписано на Zig без сторонних библиотек: AppKit, CoreGraphics и AVFAudio вызываются напрямую. Swift нужен только для генерации страниц установщика и иконок. Bundle ID: `dev.soundy.minified.app`; настройки и разрешение мониторинга ввода отдельные от исходного Soundy. Отдельное имя и путь установки: `/Applications/Soundy Minified.app`. Фиолетово-синяя иконка отличает приложение от оригинала; обе версии могут быть установлены одновременно.
